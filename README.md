# CorporateLeaders — Author Website

A responsive, modern-minimalist starter website for Biplab Bothra's book *CorporateLeaders*.

## Files
- `index.html` — complete single-page website (HTML, CSS, and a tiny year script).

## Before publishing
1. Replace the starter book description with the final synopsis.
2. Add Biplab Bothra's biography.
3. Replace the contact/social placeholders with public links you want to share.
4. Preview on desktop and mobile.

## Free publishing option: GitHub Pages
1. Sign in or create an account at https://github.com
2. Create a new **public** repository named `corporateleaders-author-page`.
3. Upload `index.html` to the repository root and commit the change.
4. Open the repository's **Settings → Pages**.
5. Under build/deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
6. Wait for GitHub Pages to publish. Your URL will look like:
   `https://YOUR-USERNAME.github.io/corporateleaders-author-page/`
7. Open the URL on a phone to test it.

## QR code
Generate the QR code only after the published URL is final. A QR code points to a URL; it does not host the page. Keep the website and URL active for as long as the printed book is in circulation. Test the printed QR at its final size and maintain good contrast.
